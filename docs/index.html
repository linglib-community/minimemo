minimemo

minimemo is a formalization in Lean 4 of memo, the probabilistic programming language of Kartik Chandra, Tony Chen, Joshua B. Tenenbaum and Jonathan Ragan-Kelley. A memo model is translated to a Lean term. The term is evaluated with exact rational arithmetic, and properties of the model are stated and proved as theorems.

1. A model, in memo

There are four utterances, green, pink, square and round, and three referents: a green square, a green circle and a pink circle. A listener thinks that a speaker picks a referent and then says something true of it. The listener hears the utterance and guesses the referent. This is the first model of the memo paper. 

@memo
def naive[u: U, r: R]():
    listener: thinks[
        speaker: chooses(r_true in R, wpp=1),
        speaker: chooses(u_said in U, wpp=denotes(u_said, r_true))
    ]
    listener: observes [speaker.u_said] is u
    listener: chooses(r_pick in R, wpp=Pr[speaker.r_true == r_pick])
    return Pr[listener.r_pick == r]

2. The same model, in Lean

This term is printed from the source above by a script that calls memo's parser. 

def naive : Model Agent Name Dom ℚ where
  axes := [(.u, .U), (.r, .R)]
  body :=
    .thinks .listener
      (.chooses .speaker .rTrue .R (.lit 1) ;;
      .chooses .speaker .uSaid .U (.op₂ denotes (.choice .uSaid) (.choice .rTrue))) ;;
    .observes .listener .speaker .uSaid .self .u ;;
    .chooses .listener .rPick .R (.expect (.op₂ eq (.query .speaker (.choice .rTrue)) (.choice .rPick)))
  ret := .expect (.op₂ eq (.query .listener (.choice .rPick)) (.choice .r))

In Lean the array is a theorem, proved by evaluation. 

theorem tensor_rows :
    tensor.rows 4 3 =
      [[1/2, 1/2, 0],
       [0,   0,   1],
       [1,   0,   0],
       [0,   1/2, 1/2]] := by
  decide +kernel

4. A second model

A pragmatic listener thinks that the speaker reasons about a listener. Its speaker chooses an utterance with weight the probability that the naive listener would give the referent that the speaker means. One line of the model changes. 

@memo
def pragmatic[u: U, r: R]():
    listener: thinks[
        speaker: chooses(r_true in R, wpp=1),
        speaker: chooses(u_said in U, wpp=naive[u_said, r_true]())
    ]
    listener: observes [speaker.u_said] is u
    listener: chooses(r_pick in R, wpp=Pr[speaker.r_true == r_pick])
    return Pr[listener.r_pick == r]

pink001

Lean

green2/53/50
pink001
square100
round03/52/5

On hearing green, the naive listener cannot decide between the two green things. The pragmatic listener leans toward the circle, because a speaker who meant the square could have said square.

5. A theorem about the two models

Suppose that a people hear green and pick the green square, and b pick the green circle. The likelihood of these data under a model is the product of the probabilities that the model gives the picks. 

def likelihood (z : Tensor ℚ) (a b : ℕ) : ℚ := z.entry [0, 0] ^ a * z.entry [0, 1] ^ b

If at least two thirds of the people pick the circle, the pragmatic listener has the greater likelihood. The theorem quantifies over all such data. 

theorem likelihood_lt {a b : ℕ} (h : 2 * a ≤ b) (hb : 0 < b) :
    likelihood NaiveListener.tensor a b < likelihood tensor a b

The demonstration of this model in the memo repository uses the counts 65 and 115, from Qing and Franke (2015). For these counts the inequality is proved by evaluation. 

theorem likelihood_lt_demo :
    likelihood NaiveListener.tensor 65 115 < likelihood tensor 65 115 := by
  decide +kernel

6. Two more theorems

A speaker who chooses the utterance first, and then a referent that it describes, gives the listener the same array as the speaker of the first model. 

theorem infer_utteranceFirst :
    (infer dom utteranceFirst).map (·.rows 4 3) = (infer dom model).map (·.rows 4 3)

For every statement and frame, multiplying the weight of a choice by a nonzero number does not change the effect of the choice. 

theorem run_chooses_mul {c : K} (hc : c ≠ 0) (α : A) (x : N) (X : D) (e : Expr A N D K) :
    run dom (.chooses α x X (.op₁ (c * ·) e)) Φ n = run dom (.chooses α x X e) Φ n

Notes

  • minimemo covers the grammar of the memo paper: chooses, observes, thinks, queries, E and Pr, and imagine.
  • In memo's demonstration the pragmatic speaker's weight is the exponential of a multiple of the listener's probability. Here it is the probability, so that the numbers are rational.
  • A foreign function such as denotes is written a second time, in Lean.
  • The memo arrays on this page were computed with memo 1.3.3.
